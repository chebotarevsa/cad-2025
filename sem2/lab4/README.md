# Лабораторная работа №4

## Тема

Взаимодействие Spring Boot и PostgreSQL.

## Цель работы

Получить практические навыки сохранения данных из Spring-приложения в базе
данных PostgreSQL с помощью Spring Data JPA.

## Ход работы

За основу взято приложение со списком задач из лабораторной работы №3.
В `pom.xml` добавлены зависимости Spring Data JPA и драйвера PostgreSQL.

Класс `Task` отмечен аннотацией `@Entity`. Поле `id` является первичным ключом
и создается автоматически. Интерфейс `TaskRepository` наследует
`JpaRepository`, поэтому для работы с задачами используются готовые методы
`save()`, `findAll()`, `findById()` и `deleteById()`.

Параметры подключения находятся в файле `application.properties`. Hibernate
автоматически создает или обновляет таблицу `tasks` при запуске приложения.

В качестве дополнительного задания в таблицу добавлены:

- дата и время создания задачи;
- приоритет;
- категория.

Авторизация и роли остались такими же, как в лабораторной работе №3:

- `user` может просматривать и добавлять задачи;
- `moderator` может также изменять статус задач;
- `admin` может изменять статус и удалять задачи.

Пароль всех пользователей: `password`.

## Подготовка базы данных

В PostgreSQL необходимо создать базу данных:

```sql
CREATE DATABASE todo_db;
```

По умолчанию используется пользователь `postgres` и пароль `postgres`. Если
пароль отличается, его можно указать при запуске:

```shell
DB_PASSWORD=ваш_пароль ./mvnw spring-boot:run
```

После запуска приложение доступно по адресу `http://localhost:8080`.

## Вывод

В ходе работы было настроено подключение Spring Boot к PostgreSQL. Задачи теперь
хранятся в таблице базы данных и не пропадают после перезапуска приложения.
