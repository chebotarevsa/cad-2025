# Лабораторная работа №5

## Тема

Разработка клиент-серверного приложения.

## Цель работы

Получить практические навыки разработки клиента, который получает данные от
Spring Boot сервера по HTTP.

## Ход работы

За основу взято приложение со списком задач из лабораторной работы №4. На
сервере добавлены REST-методы:

- `GET /api` - получение списка задач;
- `POST /api` - добавление задачи;
- `DELETE /api/{id}` - удаление задачи.

Для клиента созданы две формы на Java Swing. `LoginForm` принимает логин и
пароль, а `TaskManagerForm` показывает задачи в таблице и отправляет запросы на
сервер. Для передачи логина и пароля используется Basic Authentication.

Клиент выводит все дополнительные данные из прошлой работы: дату создания,
приоритет и категорию. Новые задачи можно добавлять из клиентского приложения.
Удаление доступно только пользователю `admin` и дополнительно проверяется на
сервере. Сортировка выполняется нажатием на заголовок столбца таблицы.

## Запуск

Перед запуском необходимо создать базу PostgreSQL `todo_db`.

Сервер запускается командой:

```shell
DB_PASSWORD=пароль_от_postgres ./mvnw spring-boot:run
```

После запуска сервера в отдельном окне терминала запускается клиент:

```shell
./mvnw exec:java
```

Доступные пользователи:

- `user`;
- `moderator`;
- `admin`.

Пароль для всех пользователей: `password`.

## Вывод

В ходе лабораторной работы был создан настольный клиент, который получает и
изменяет данные на Spring Boot сервере через REST API.
