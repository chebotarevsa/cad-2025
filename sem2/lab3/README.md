# Лабораторная работа №3

## Тема

Spring Security.

## Цель работы

Получить практические навыки настройки аутентификации и разграничения
доступа пользователей в приложении Spring Boot.

## Ход работы

За основу было взято приложение со списком задач из лабораторной работы №2.
В файл `pom.xml` добавлена зависимость Spring Security.

В классе `SecurityConfig` созданы три пользователя:

- `user` с ролью USER;
- `moderator` с ролью MODERATOR;
- `admin` с ролью ADMIN.

Пароль для всех пользователей: `password`.

После запуска приложения пользователь должен авторизоваться. Все роли могут
просматривать и добавлять задачи. Роль MODERATOR может отмечать задачи
выполненными, а роль ADMIN может изменять и удалять задачи.

В качестве дополнительного задания была добавлена роль ADMIN. Она использует
функциональность удаления с подтверждением из прошлой лабораторной работы.

Для запуска приложения используется команда:

```shell
./mvnw spring-boot:run
```

После запуска приложение доступно по адресу `http://localhost:8080`.

## Вывод

В ходе лабораторной работы в приложение была добавлена авторизация и
разграничение доступа. Были изучены роли пользователей и аннотация
`@PreAuthorize`.
