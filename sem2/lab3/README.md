# Лабораторная работа №3
# Spring Security

## Цель работы
Получить практические навыки настройки аутентификации и разграничения
доступа пользователей в приложении Spring Boot.

## Ход работы
В этой работе 
1. Был изучен теоретический материал;
2. Написано приложение следуя примеру;
3. Выполнено доп. задание: добавить доп. роль.

В классе SecurityConfig настроены три учетные записи: 
1. user (USER); 
2. moderator (MODERATOR);
3. admin (ADMIN)

Логин: имя пользователя
Пароль password

После запуска требуется авторизация. 
Просмотр и добавление задач доступны всем ролям, отмечать выполненными 
может MODERATOR, а изменять и удалять — ADMIN. Дополнительно роль ADMIN 
использует удаление с подтверждением из прошлой лабораторной.

Для обработки ошибки доступа (403 Forbidden) 
создан ErrorController, который перехватывает путь /error 
и перенаправляет пользователя на страницу error.html 
с сообщением об отсутствии прав вместо стандартной страницы ошибки Spring.

## Вывод
Получены практические навыки настройки аутентификации и разграничения
доступа пользователей в приложении Spring Boot.
