# Лабораторная работа №6

## Тема

Разработка клиентского приложения под Android.

## Цель работы

Получить практические навыки создания Android-приложения, которое получает
данные от Spring Boot сервера через REST API.

## Ход работы

Было создано простое Android-приложение на Java. Оно состоит из двух экранов:

- `LoginActivity` - ввод логина и пароля;
- `TaskManagerActivity` - получение и отображение списка задач.

Для обращения к серверу используется Retrofit. JSON-ответ автоматически
преобразуется в объекты `Task` с помощью Gson. Задачи выводятся через
`RecyclerView` и `TaskAdapter`.

Android-эмулятор обращается к серверу на компьютере по адресу
`http://10.0.2.2:8080`. В файле `network_security_config.xml` разрешено
локальное HTTP-соединение с этим адресом. В `AndroidManifest.xml` добавлено
разрешение на использование интернета.

Приложение показывает название, описание, статус, приоритет, категорию и дату
создания задачи.

## Запуск

1. Запустить PostgreSQL и сервер из лабораторной работы №5.
2. Открыть папку `sem2/lab6` в Android Studio.
3. Дождаться загрузки Gradle-зависимостей.
4. Создать и запустить Android-эмулятор.
5. Запустить приложение кнопкой Run.

Данные для входа:

- логин: `user`, `moderator` или `admin`;
- пароль: `password`.

## Вывод

В ходе работы был создан Android-клиент, который проходит авторизацию и
получает список задач от Spring Boot сервера по HTTP.
