# Лабораторная работа №6
# Разработка клиента под Android

## Цель работы
Получить практические навыки работы с Spring Framework: разработка
клиент-серверных приложений.

## Ход работы
1. Изучен теоретический материал.
2. Написано приложение по примеру.
3. Выполнено дополнительное задание.

## Дополнительное задание
1. Реализовала вывод дополнительных данных из БД, которые были добавлены
   в прошлой работе.
2. Реализовала функционал удаления задач в БД из клиентского
   приложения (право на удаление только у определённой роли).
3. Реализовала функционал добавления задач в БД из клиентского
   приложения.
4. Реализовала функционал сортировки задач.
5. Улучшила пользовательский интерфейс.

## Вывод
Получены практические навыки разработки клиент-серверных приложений.
