# Gradle. Базовое приложение Spring

## Ход работы
Установила Gradle, Temurin. 
Сделала консольное приложение разработанное с помощью фреймворка Spring и конфигурируемое с помощью Java-конфигурации.
Приложение читает данные о товарах для магазина из csv-файла и выводит его в консоль в виде таблицы.
